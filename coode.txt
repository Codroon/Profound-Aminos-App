ReachShip Multi-Carrier Shipping API (Version 1.0)
Overview
The ReachShip Multi-Carrier Shipping API is a flexible, modern, and easy-to-use API that aggregates various shipping APIs into a single interface. It provides multi-carrier shipping functionality, supporting both regional and international carriers. By integrating with your eCommerce store, ReachShip enables access to essential shipping features, including:

Obtaining shipping rates
Generating and printing shipping labels
Scheduling pickups
Tracking shipments
Managing carrier credentials

The API is designed for seamless integration, supported by excellent developer resources.

API Endpoints
1. API Authorization
Obtain an OAuth token for API transactions. The token expires every 30 days and must be regenerated.

Method: GET
Endpoint:

Sandbox: https://api.reachship.com/sandbox/v1/oauth/token
Production: https://api.reachship.com/production/v1/oauth/token


Query Parameters:

grant_type (string, required): Set to "client_credentials"
client_id (string, 34 characters): Client ID from ReachShip dashboard (e.g., Client_ID)
client_secret (string, 32 characters): Client Secret from ReachShip dashboard (e.g., Client_Secret)


Request Body: application/x-www-form-urlencoded
Responses:

200 Success: Returns { "access_token": "reachship access token", "token_type": "bearer" }
400 Missing Parameters
422 Invalid Credentials
500 Server Error


Request Sample:
plaintextgrant_type=client_credentials&client_id=Client_ID&client_secret=Client_secret



2. Rates and Transit Times
Retrieve pre-ship rating information to determine shipping costs.

Method: POST
Endpoint:

Sandbox: https://api.reachship.com/sandbox/v1/rates
Production: https://api.reachship.com/production/v1/rates


Header Parameters:

Authorization (string, required): Bearer token (e.g., Bearer access_token)


Request Body: application/json

rates_options (object): Optional rate options
shipment (object, required): Includes ship_to, ship_from, and packages arrays


Responses:

200 Success: Returns an array of rate objects, e.g.:
json[
  {
    "companyName": "FEDEX",
    "serviceName": "FedEx First Overnight®",
    "estimatedDelivery": "NA",
    "totalBaseCharge": 137.92,
    "totalChargeWithTaxes": 164.81,
    "currency": "USD",
    "serviceCode": "FIRST_OVERNIGHT",
    "reachshipAccountIdentifier": "fedex account 1",
    "extraCharges": {}
  }
]

400 Bad Request
422 Failure
500 Server Error


Request Sample:
json{
  "shipment": {
    "ship_to": {},
    "ship_from": {},
    "packages": []
  }
}



3. Create Shipment
Process and submit shipping requests to generate a shipping label.

Method: POST
Endpoint:

Sandbox: https://api.reachship.com/sandbox/v1/print-label
Production: https://api.reachship.com/production/v1/print-label


Header Parameters:

Authorization (string, required): Bearer token (e.g., Bearer access_token)


Request Body: application/json

carrier (object, required): Includes name, service_code, and account_name
additional_options (object): Optional settings
shipment (object, non-empty): Includes ship_to, ship_from, ship_date, and packages
shipments (array of objects, non-empty): Optional
order (object): Optional
order_and_pickup (object): Optional
label (object): Optional


Responses:

200 Success


Request Sample (UPS Example):
json{
  "carrier": {
    "name": "UPS",
    "service_code": "03",
    "account_name": "ups-account-01"
  },
  "shipment": {
    "ship_to": {},
    "ship_from": {},
    "ship_date": "2021-09-01",
    "packages": []
  }
}

Header Parameters:

Integration Notes

Sandbox vs. Production: Use sandbox endpoints for testing and production endpoints for live operations.
Authorization: All endpoints (except /oauth/token) require a valid Bearer token in the Authorization header.
Developer Support: ReachShip provides excellent resources for integration. Visit the ReachShip dashboard for Client ID, Client Secret, and additional documentation.
Token Expiry: OAuth tokens expire every 30 days and must be regenerated using the /oauth/token endpoint.
